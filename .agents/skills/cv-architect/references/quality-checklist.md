# Rúbrica de auditoría CV

Evaluar cada dimensión como Alto / Medio / Bajo con evidencia textual; no declarar una puntuación ATS certificada.

| Dimensión | Qué revisar |
|---|---|
| Identidad | Nombre, teléfono/email, LinkedIn, ciudad consistentes |
| Posicionamiento | Titular y resumen se ajustan a arquitectura senior y rol objetivo |
| Evidencia de impacto | Bullets incluyen alcance, decisiones, resultados verificables |
| Precisión | Cargos, fechas, superposiciones, herramientas y títulos validados |
| Relevancia | Experiencia más reciente y logros afines con vacante priorizados |
| ATS | Texto editable, encabezados sencillos, sin columnas imposibles de extraer |
| Brevedad | Sin duplicaciones extensas ni portadas decorativas para ATS |
| Tecnologías | Habilidades contextualizadas, sin inflar experiencia |
| Formación | Estudios, certificación, curso y acreditación claramente diferenciados |
| Redacción | Verbos concretos, terminología estable, ortografía, pasado/presente correctos |

## Plantilla de logros sin invención
- «Diseñé/definí [artefacto o arquitectura] para [dominio o proceso], aplicando [decisión/patrón], con el objetivo de [beneficio previsto]». No reportar beneficio como resultado real sin validación.
- «Lideré [alcance respaldado] en [contexto], coordinando [grupos/equipos sustentados] para [entregable]».
- Con métricas confirmadas: «Optimicé [componente], reduciendo [métrica] de [base] a [resultado] durante [periodo]», únicamente con cifras del usuario.
